Estructura económica de las canastas

Las tres canastas no se consideran tres compras diferentes. Son tres tamaños de participación económica dentro de una misma compra colectiva.

¿Qué significa esto?

La Semilla representa una participación económica de S/15.
La Básica representa 25/15 = 1.67 participaciones Semilla.
La Familiar representa 35/15 = 2.33 participaciones Semilla.

Por tanto, la diferencia entre ellas no consiste principalmente en tener productos distintos, sino en tener una mayor o menor capacidad de compra dentro de la misma estructura colectiva.

Productos disponibles para la compra colectiva

Aquí solamente se registra el precio real encontrado en el mercado y si el producto está disponible para esta ronda.

La cantidad no se introduce manualmente. La cantidad será calculada por el algoritmo.

Regla del sistema

Las canastas determinan cuánto dinero existe para comprar alimentos.
Los precios determinan cuánto producto puede comprarse con ese dinero.
La estructura de productos determina cómo se distribuye ese presupuesto entre alimentos diversos.

No se define un mínimo arbitrario por producto.

Compra colectiva

El sistema primero determina el tamaño económico de la ronda y el presupuesto disponible para alimentos.

Después utilizará los precios reales del mercado para transformar ese presupuesto en cantidades de productos.

La compra se realiza de manera consolidada. La distribución individual entre familias ocurre después de conocer la compra total.
